# User Space Programs (`user/programs/`)

## Purpose
Core user-space command-line utilities and test programs:
- Standard tools: `ls`, `cat`, `echo`, `kill`, `ps`.
- Ring 3 test binaries verifying isolation, page fault prevention, invalid syscall error handling, and preemption.
